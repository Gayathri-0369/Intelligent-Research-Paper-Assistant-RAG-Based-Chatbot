# Intelligent-Research-Paper-Assistant-RAG-Based-Chatbot
Developed an Intelligent RAG-Based Chatbot using Python, LangChain, Groq LLM, and ChromaDB to answer questions from research papers. Implemented PDF processing, text chunking, embeddings, semantic search, and source citations. Integrated a Gradio interface with follow-up question handling and RAGAS evaluation to improve answer reliability.
